### 15.1 — Магические методы
- Для `Product` реализован `__str__` в формате:  
  **Название продукта, X руб. Остаток: Y шт.**
- Для `Category` реализован `__str__` с подсчётом общего количества товара.
- Для `Product` реализован `__add__`:
  - товары можно складывать только если класс совпадает  
  - иначе выбрасывается `TypeError`.
