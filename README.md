# Homework 14.1 — классы Product и Category

В проекте реализованы классы `Product` и `Category`.

- `Product` хранит название, описание, цену и количество товара.
- `Category` хранит название, описание и список товаров.
- Для `Category` добавлены атрибуты класса `category_count` и
  `product_count`, которые автоматически подсчитывают количество
  созданных категорий и товаров.

## Homework 16.1 – Наследование и ограничения типов

- Добавлены классы-наследники `Smartphone` и `LawnGrass` от базового класса `Product`.
- Ограничено сложение продуктов: складывать можно только объекты одного типа, при попытке сложить разные типы выбрасывается `TypeError`.
- Метод `Category.add_product` теперь принимает только объекты `Product` или его наследников, иначе выбрасывается `TypeError`.
