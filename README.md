# Homework 14.1 — Классы Product и Category

В данном задании реализованы классы `Product` и `Category` для работы
с товарами и категориями.

- `Product` хранит название, описание, цену и количество товара.
- `Category` хранит название, описание и список товаров, а также
  содержит атрибуты класса `category_count` и `product_count`,
  которые автоматически подсчитывают количество созданных категорий
  и товаров.
